# mophila 言語 下書き

まだ決めていないこと。決まって実装したものはここから消し、docs/mophila-spec.md に書く。

## 1. コンパイル

今はインタプリタ。実測ではキーフレームの式の評価はフレームの 2〜7% で、ネイティブ化しても全体は 5% 程度しか縮まない。LLVM IR を出す案はあるが、速さ以外の目的が決まってから。

## 2. サイズ記法

`1/3` のような分数で、幅基準か高さ基準かが分かり、縦横比が保たれる書き方。今は `w` と `h` を数で書くしかない。

## 3. Tuple の展開

`Pos(...pos)` や `f(...args)` のように Tuple / List を引数に展開する記法。今は `f(xs[0], xs[1])` と書くしかない。
