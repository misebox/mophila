# 見た目を作る

色・構図・文字・動きの質。何を伝えるかの組み立ては [presentation.md](presentation.md)。

## 色

背景と面と強調の 3 段だけで足りる。増やすほど、どれを見ればいいか分からなくなる。

- **純白と純黒を使わない**。`#ffffff` の背景は目が痛く、`#000000` は影が置けない。`#f4f1ea` や `#1a1d23` のように少し寄せる
- **アクセントは 1 つ**。「今見るべきもの」にだけ使う。2 つ目を足すと、どちらも目立たなくなる
- **面の色は背景から作る**。`color` module の混色で背景に少し混ぜると、勝手に馴染む。無関係な色を並べない
- **明度で差をつけ、彩度で差をつけない**。彩度の高い色を 2 つ並べると、どちらが手前か分からなくなる
- **同じ意味には同じ色**。図の「入力」がある色なら、別の場面でも同じ色

```
import color

let bg = #f4f1ea
let ink = #1a1d23
let accent = #e04040
let panel = color.mix(bg, ink, 0.06)      # 面。背景に文字色を少し混ぜる
let line = color.mix(bg, ink, 0.18)       # 罫線
```

- 段階のある色 (グラフの系列、深さ) は、色相と彩度を止めて明度だけ動かす
- 透明度で薄くするより、背景に混ぜた色を使うほうが重なりに強い。`opacity` は「出入り」に取っておく

## 構図

Composition の `box` が座標系。ピクセルではないので、余白も図形の大きさもこの単位で決める。出力の大きさは `render --size` が決めるので、構図は解像度に依らない。

- **箱の比を先に決める**。16:9 の動画なら `box = Vector(16, 9)`。別の比で書き出すと余白が付くので、中身は箱の内側で完結させる
- **余白を先に決める**。`box = Vector(16, 9)` なら外周 0.8 を空ける。中身はその内側に置く
- **割合で決まるものは Length で書く**。箱の高さの 2 割の円は `20vy`、幅の半分の位置は `50vx`。箱の大きさを変えても、構図の比が保たれる
- **中心は `center`**。中央に置くものは `position = center`、中心から周りに置くものは `center + polar(20vy, 角度)`。入れ子の Composition の中では、その Composition の中心になる
- **位置は数えられる値にする**。0.8, 2.4, 4.0 のように刻みを決めて並べる。目分量の 3.17 を散らさない
- **揃える**。左端か中心のどちらかに揃え、混ぜない。並べる位置は目分量で書かず、`layout` module に計算させる
- **大きさで順位を作る**。主役は他の 1.5 倍以上。同じ大きさのものが並ぶと、どれが主役か分からない
- **anchor を使う**。`Rect` は `position` が中心になる。左上を基準にするなら `anchor = Vector(0, 0)`。大きさを変えても基準が動かない
- **回転と拡大の中心は anchor**。時計の針なら、軸に `anchor` を置いて `rotation` を動かす
- 線の太さは全体で 2 種類まで (`strokeWidth`)。角の丸み (`Rect` の `radius`) も 1 種類に揃える
- 背景は `Rect(position = Vector(0, 0), anchor = Vector(0, 0), w = 16, h = 9, fill = ...)` を先に置く。後に置いたものが手前

## 文字

- **大きさは 3 段**。見出し・本文・補足。中間の大きさを足さない
- **1 行の長さ**。日本語なら 1 行 30 文字前後、英数なら 60 字前後で `w` を決めて折り返す
- **箱の中に置くなら余白**。幅は目分量で決めず、TextArea が置いたときに占める大きさを測るメソッドで測る。`fontSize × 文字数 × 0.6` (英数) / `× 1.0` (日本語) は当てにならないときの目安

```
let t = TextArea(position = Vector(1, 1), anchor = Vector(0, 0), text = s, fontSize = 0.6)
let size = t.size()                       # 置いたときの幅と高さ (箱の座標)
if size.x > box_width { ... }             # はみ出すなら fontSize を下げる
next_y = next_y + size.y + gap            # 重ならないように次を置く
```

- 行の寄せ方は `align` で決める。左揃えの文字の左端を揃えるなら、`anchorRatio = Vector(0, 0.5)` で左端を `position` に合わせる
- **太さで強調しない**。色か大きさで差をつける
- コードを見せるなら等幅を指定する (`font = "Menlo"` など)。指定が無いと環境で幅が変わって、折り返しがずれる
- 和文の等幅は入っていないことが多い。`Menlo` を指定すると和文だけ別のフォントで補われ、桁が揃わない。`mophila fonts` で入っている名前を確かめる

## 動き

動きは `func (t)` の中の `ease` で書く。区間の長さと始まりを数で決める。

- **距離が短いほど速く**。画面を横切るなら 0.6〜1.0 秒、少し動かすだけなら 0.2〜0.4 秒。同じ時間で動かすと、短い移動が間延びする
- **等速は機械的に見える**。物が動くなら `ease`、出てくるなら `ease_out` (減速して止まる)、消えるなら `ease_in` (加速して去る)
- **同時に動かすのは 1 つ**。複数あるなら 0.06〜0.1 秒ずらす (stagger)。`i * stagger` を `ease` の時刻に足す。全部いっぺんに動くと何も追えない
- **動きの向きに意味を持たせる**。増えるものは上か右、戻るものは逆。場面をまたいで同じ向きにする
- **止まっている時間を作る**。動き続けると、どこを見ればいいか分からない。見せたい形になったら 1 秒は止める。`ease` は区間の外で端の値に止まるので、止める時間は何も書かなくてよい
- **回すのは属性で**。頂点を計算し直さない。Group の `rotation` を動かせば、中の座標はそのままで全体が回る
- **円運動や振動は式で**。`center + polar(r, tau * t / 周期)` や `sin` を `func (t)` に直接書く。キーフレームを刻んで近似すると多角形になる
- **出入りは `opacity` か、`in` と `out`**。フェードは `ease` で `opacity` を動かす。`out` を過ぎた Layer は存在しないので、消えた後の値を気にしなくてよい

## fps と見え方

- 既定は 10 fps。図形が大きく動くとカクつくので、動きを見せるなら 24〜30 にする
- 逆に、文字とカードだけの場面は 10 fps で足りる。ファイルが軽くなる
- GIF は 256 色。グラデーションや Shader を GIF にすると帯が出る。動画にするか、色数の少ない絵にする

## 確認

`sheet` で複数の時刻を一度に見ると、色と配置のばらつきが分かる。動きの質は `preview` でしか分からない。

```
mophila sheet a.moph -o sheet.png --every 5s
mophila preview a.moph
```
